# 注意力输出的"精确项 + 近似项"推导

> 用途：把"PISA 的分段策略到底在算什么、丢掉了什么、误差有多大"变成可写进报告的公式与数字。
> 读完这份文档你应该能回答三个答辩必问题：**补偿项换来多少加速、丢掉哪一阶、误差上界是多少。**

> 因此第 9 节列出必须逐条核对的清单。**报告里请明确区分「我的推导」与「原文的机制」。**

## 1. 设定与真实数值（Wan2.1-T2V-1.3B, 480p, 81 帧）

单个注意力头（head_dim = d = 128，序列长度 N）：

```text
logits:    s_ij = q_i · k_j / sqrt(d)          (i, j = 1..N)
输出:      o_i  = Σ_j exp(s_ij) v_j / Σ_j exp(s_ij)
稳定化写法（数值实现必须如此）：
  c_i = max_j s_ij
  w_ij = exp(s_ij - c_i) ∈ (0, 1]              # 行内最大权重恰好为 1
  记 n_i = Σ_j w_ij v_j (分子), z_i = Σ_j w_ij (分母), 则 o_i = n_i / z_i
```

Wan2.1 的两个细节（务必在代码里确认）：

```text
1) qk_norm = True  ->  s_ij 用的是 RMSNorm 之后的 q, k，logit 尺度被重新归一化
2) 3D RoPE         ->  实际是 s_ij = q~_i · k~_j,  q~ = RoPE_3D(RMSNorm(q))
   关键性质：RoPE 是旋转，对 q、k 是线性的，所以 s_ij 对 q~、k~ 仍是双线性形式，
   后面所有"矩可以预聚合"的结论仍然成立；但 logit 的分布（因而 Δ 的分布）会变。
```

你的配置对应的量级（后面所有数字都基于此）：

```text
dim = 1536, heads = 12, head_dim d = 128, layers L = 30, ffn_dim = 8960
VAE stride (4, 8, 8), patch (1, 2, 2), 81 帧 -> 21 个 latent 帧
480p: 832x480 -> latent 104x60 -> patch 后 52x30 = 1560 token/帧 -> N = 21*1560 = 32760
720p: 1280x720 -> latent 160x90 -> patch 后 80x45 = 3600 token/帧 -> N = 21*3600 = 75600
每个 head 每层（dense，两个 matmul）:  4 * N^2 * d
  N=32760 : 4 * 1.0732e9 * 128 = 5.50e11 FLOPs
  N=75600 : 4 * 5.7154e9 * 128 = 2.93e12 FLOPs
每层 linear（QKV/O proj + FFN）:  约 2.42e12 (480p) / 5.59e12 (720p)
  => 自注意力占总 FLOPs 比例:  480p = 73%,  720p = 86%
```

**结论 1**：注意力占比 73%（480p）/ 86%（720p），所以"只优化注意力"的 Amdahl 上限是
`1/(0.27 + 0.73/S)` 与 `1/(0.137 + 0.863/S)`，S 为 kernel 层加速比。这是 1.5x–2.5x 目标的可达性边界。

## 2. 精确拆分（恒等式，不含任何近似）

把 key 集合划成"精确集 S"与"近似集 C"（S ∩ C = ∅）：

```text
n_i = n_i^S + n_i^C ,   n_i^S = Σ_{j∈S} w_ij v_j ,  n_i^C = Σ_{j∈C} w_ij v_j
z_i = z_i^S + z_i^C ,   z_i^S = Σ_{j∈S} w_ij   ,  z_i^C = Σ_{j∈C} w_ij
定义质量比:   ρ_i = z_i^C / z_i = z_i^C / (z_i^S + z_i^C) ∈ [0, 1)
定义段内均值: o_i^S = n_i^S / z_i^S ,  o_i^C = n_i^C / z_i^C
=>  o_i = (1 - ρ_i) * o_i^S + ρ_i * o_i^C          （恒等式，无近似）
```

这是整份推导的支点：**输出是"精确段输出"与"近似段输出"的凸组合，权重是质量比 ρ_i。** 于是：

```text
|| o_i - o_i^S || = ρ_i * || o_i^S - o_i^C ||  ≤  2 ρ_i * max_j ||v_j||
```

**结论 2**：硬丢弃（order-0）造成的偏差严格正比于 ρ_i。ρ_i 是逐行可测量的量，
所以"误差有多大"不是玄学，而是一个可以打点记录的统计量。

## 3. 泰勒展开：以 logit 为变量

对 j ∈ C 记偏差 `δ_ij = s_ij - c_i ≤ 0`（c_i 是行最大值），则 `w_ij = exp(δ_ij)`。

```text
exp(δ) = Σ_{n=0}^{p} δ^n / n! + R_p(δ)
分子（向量）:   n_i^C ≈ Σ_{j∈C} ( Σ_{n=0}^{p} δ_ij^n / n! ) v_j
分母（标量）:   z_i^C ≈ Σ_{j∈C} ( Σ_{n=0}^{p} δ_ij^n / n! )
```

逐阶展开成"可预聚合的矩"（这是全部工程价值的来源）：

```text
n = 0 项:
  Σ_j 1 * v_j = V_C ,  其中 V_C := Σ_{j∈C} v_j        ∈ R^d
  Σ_j 1      = |C|
n = 1 项（利用 Σ_j δ_ij v_j = Σ_j (q~_i · k~_j) v_j - c_i Σ_j v_j）:
  M_C := Σ_{j∈C} k~_j v_j^T                            ∈ R^{d×d}
  S_C := Σ_{j∈C} k~_j                                  ∈ R^d
  Σ_j δ_ij v_j = M_C q~_i - c_i V_C
  Σ_j δ_ij     = S_C · q~_i - c_i |C|
  => 分子一阶:  n~_i^C = M_C q~_i + (1 - c_i) V_C
  => 分母一阶:  z~_i^C = (1 - c_i)|C| + S_C · q~_i
n = 2 项:
  分母:  G_C := Σ_{j∈C} k~_j k~_j^T                    ∈ R^{d×d}
         Σ_j δ_ij^2 = q~_i^T G_C q~_i - 2 c_i (S_C · q~_i) + c_i^2 |C|
         => 只需一个 d×d 矩阵，应用代价 O(d^2)/query  —— 便宜
  分子:  Σ_j δ_ij^2 v_j = Σ_{a,b} q~_{ia} q~_{ib} T_C[a, b, e]
         T_C := Σ_{j∈C} k~_ja k~_jb v_je                ∈ R^{d×d×d}
         => 需要一个三阶张量（d^3 = 2.1e6 个元素）—— 昂贵
```

**结论 3（"混合阶"在数学上是被迫的，不是调参）**：

```text
分母（标量输出）二阶只要 d×d 矩 G_C，几乎免费；
分子（d 维向量输出）二阶需要 d×d×d 张量 T_C，聚合与应用代价都涨 d 倍。
因此"混合阶"最自然的形态是：分子一阶 + 分母二阶（或分母一阶 + 精确统计量）。
```

## 4. 成本核算：补偿到底值多少钱

以下是**每个 head、每层**的 FLOPs（480p, N=32760, d=128, 令近似集 |C| = 0.8N ≈ 26200）：

| 方案 | 聚合开销 | 每 query 应用 | 合计 | 占"精确计算 C 集合"比例 | 额外显存 |
|---|---|---|---|---|---|
| 硬丢弃（order-0） | 0 | 0 | 0 | 0% | 0 |
| **一阶补偿（分子）** | \|C\|d² = 4.3e8 | Nd² = 5.4e8 | **9.7e8** | **0.22%** | 一个 d×d |
| 二阶补偿（仅分母） | \|C\|d² = 4.3e8 | Nd² = 5.4e8 | 9.7e8 | 0.22% | 一个 d×d |
| 二阶补偿（分子） | \|C\|d³ = 5.5e10 | Nd³ = 6.9e10 | 1.24e11 | 28% | 4.2MB/head·layer，全模型约 1.5GB |
| 精确计算 C 集合 | — | — | 4N\|C\|d = 4.4e11 | 100% | — |

把"一阶"折算成相对稠密注意力的比例，得到一个非常干净的公式：

```text
compensation_overhead / dense_attention  ≈  (1 + ρ) * d / (2N)
代入: 480p(N=32760), ρ=0.8, d=128  ->  (1.8 * 128) / 65520 = 0.35%
      720p(N=75600), ρ=0.8, d=128  ->  0.15%
      短序列 N=4096                ->  2.8%
```

**结论 4**：在 480p/81 帧这个尺度，一阶泰勒补偿的开销只占稠密注意力的 **0.35%**。折算成端到端加速比：

```text
纯硬丢弃 (ρ=0.8): kernel 层 S = 1/0.2   = 5.00x -> 端到端上限 1/(0.27 + 0.73/5.00) = 2.40x
一阶补偿 (ρ=0.8): kernel 层 S = 1/0.202 = 4.95x -> 端到端上限 1/(0.27 + 0.73/4.95) = 2.39x
```

**补偿项几乎"免费"（端到端只损失约 0.4% 的相对加速比），却（按第 7 节机制假设）能消掉主要的背景闪烁。**
这是你这个选题在"效率-质量"上真正站得住的论点。

同一稀疏率下不同分辨率的对照（体现"超长序列"才是适用区间）：

```text
ρ=0.8, 一阶补偿:   480p -> 2.39x     720p -> 1/(0.137 + 0.863/4.95) = 3.21x
补偿开销占比:      480p -> 0.35%     720p -> 0.15%
```

## 5. 误差上界

### 命题 1（截断余项）

对任意 δ ≤ 0：`| exp(δ) - 1 - δ | ≤ δ² / 2`

证明要点：`exp(δ) = 1 + δ + ∫_0^δ (e^t - 1) dt`。对 t ≤ 0 有 `0 ≤ 1 - e^t ≤ -t`（即 e^t ≥ 1+t），
于是 `|∫_0^δ (e^t-1) dt| ≤ ∫_δ^0 |t| dt = δ²/2`。∎
对照：order-0 的余项是 `|e^δ - 1| ≤ 1`（权重最大为 1）。**一阶把误差从 O(1) 压到 O(δ²)。**

### 命题 2（近似集分子误差）

记 `Δ_i = max_{j∈C} |δ_ij| = -min_{j∈C} δ_ij`（逐行最大 logit 落差，可实测算出）：

```text
|| n_i^C - n~_i^C ||  ≤  (Δ_i² / 2) * Σ_{j∈C} ||v_j||
又因为 δ_ij ≤ -Δ_i  =>  w_ij ≤ exp(-Δ_i)  =>  || n_i^C || ≤ exp(-Δ_i) * Σ_{j∈C} ||v_j||
所以"被补偿部分的相对误差"满足:
        ε(Δ)  ≤  (Δ² / 2) * exp(Δ)                ← 闭式上界
  Δ = 0.20 -> ε ≤ 2.4%
  Δ = 0.27 -> ε ≤ 5.0%
  Δ = 0.37 -> ε ≤ 10%
  Δ = 0.49 -> ε ≤ 20%
  Δ = 1.00 -> ε ≤ 136%   （界失效，此时一阶补偿不再安全）
```

注意这是**最坏情况上界**（假设所有 v_j 同向且取到最坏 δ），实际误差通常显著更小；
报告里请把实测误差与这条理论曲线画在同一张图上（第 10 节实验 V1）。

### 命题 3（端到端输出误差）

设 `E_n = n~_i^C - n_i^C`、`E_d = z~_i^C - z_i^C`，近似后的输出记为 ô_i，则：

```text
ô_i - o_i = (E_n - o_i * E_d) / (z_i + E_d)
=> || ô_i - o_i ||  ≤  ( ||E_n|| + ||o_i|| * |E_d| ) / (z_i - |E_d|)
由于 z_i ≥ 1（行最大权重贡献 1），且 z_i^C = ρ_i z_i，代入命题 2 的量级:
    || ô_i - o_i ||  ≲  ρ_i * ε(Δ_i) * (1 + ||o_i||)
```

**结论 5（可操作形式）**：`输出误差 ≈ ρ_i × ε(Δ_i)`。

```text
ρ_i     = "你在哪丢"   （该行被近似掉的质量比例，逐行可测）
ε(Δ_i)  = "你丢得多糟" （一阶截断的相对误差，由该行 logit 落差决定）
硬丢弃相当于 ε = 1，即误差 ≈ ρ_i；一阶补偿把误差乘上 ε(Δ) ≈ Δ²e^Δ/2，Δ ≤ 0.3 时约 6% 以下。
```

分子与分母必须用同一阶数的近似，这是关键设计原则：若只近似分子而保留精确分母，
`E_n - o_i E_d` 中的抵消项 `o_i E_d` 消失，误差不再自动降阶，输出模长会发生系统性偏移——
在视频里通常表现为整体亮度/对比度漂移，而不是干净的残余噪声。

## 6. 分段（piecewise）判据：阈值与"精确预算该花在哪"

### 6.1 先纠正一个容易搞错的点：Δ 有两个，方向相反

前文的式子对两个不同的量敏感，混淆它们会把阈值直接定错：

```text
Δ_max(A) = max_{j∈A} |δ_j|   —— 被【补偿】集合里最深的那个 key。
                              它控制补偿的【相对误差】：ε(Δ) = (Δ²/2)e^Δ 随它增长。
Δ_min(D) = min_{j∈D} |δ_j|   —— 被【丢弃】集合里最浅的那个 key（尾部上边缘）。
                              它控制被丢质量的【上界】：z^D ≤ |D| * exp(-Δ_min(D))。
```

补偿看"最深"，丢弃看"最浅"。早先版本里用同一个 Δ_max 去写丢弃判据是错的（会给出过于悲观的门槛）。

### 6.2 正确的三段划分

直接用阈值定义，不要用"位置窗口"：

```text
A（补偿，近端）:  |δ| ≤ Δ_1
D（丢弃，远端）:  |δ| ≥ Δ_2，且要求 z^D ≤ ε_tol * z
E（精确，中段）:  Δ_1 < |δ| < Δ_2
```

**为什么 A 段放在"近端"而不是通常的 top-k**：一阶近似在 δ=0 处是**精确**的（1+0 = e⁰），
单 key 相对误差 `1 - e^{-δ}(1+δ)` 随 |δ| 单调递增（实测 break-even 恰在 |δ|=1，见
`sparse_attn_proto/test_sparse_attn.py`）。也就是说，**注意力质量最大的那些 key 恰恰是补偿最准的地方**，
把它们全部拿去精确计算是浪费；真正需要精确计算的是"中段"——那里一阶已经不准（|δ| > ~0.5），
但质量又不可忽略。

### 6.3 阈值怎么定（全部可由实测 δ 直方图算出）

```text
Δ_1 : 由 ε(Δ_1) = (Δ_1²/2) e^{Δ_1} ≤ τ 反解
      τ=5% -> 0.27 ;  10% -> 0.37 ;  20% -> 0.49
Δ_2 : 由 z^D ≤ ε_tol * z 反解（在"按 logit 排序后的质量累积曲线"上取分位点）
保守充分条件（便于写进报告）: Δ_min(D) ≥ ln( |D| / (ε_tol * z^E) )
硬下界提醒: |δ| > 1 时一阶近似已经比直接丢弃更差（1+δ 变号），
            所以 Δ_1 必须显著小于 1，别把长尾塞进补偿项。
```

### 6.4 可做的消融："精确预算应该花在最高 logit 上吗？"

在合成分布上比较两种分配（N=192, ε_tol=2%, Δ_1=0.4，**两者精确 key 数完全相同**，故计算量可比）：

| logit std | 精确 key 数 | 稀疏率 | top-m 精确（常规做法） | 中段精确（本推导） |
|---|---|---|---|---|
| 0.056 | 0 | 1.00 | 0.0086 | 0.0086 |
| 0.112 | 19 | 0.90 | **0.041** | 0.122 |
| 0.225 | 134 | 0.30 | 0.560 | **0.131** |
| 0.393 | 169 | 0.12 | 0.210 | **0.116** |
| 0.674 | 173 | 0.099 | 0.0946 | 0.092 |
| 1.123 | 163 | 0.151 | **0.048** | 0.065（p90 恶化到 0.34） |

结论：**在中间区间（std≈0.2–0.4，也是补偿唯一有效的区间）中段精确方案误差低 2–4 倍；
在极分散时反而更差。** 所以"精确预算花在哪"是一个可以被实验区分的真实设计选择，
不是实现细节 —— 这是本项目最像"研究"的一块，也是与单纯复现的最大区别。

**结论 6**：能稀疏到多少由 δ 的分布决定，而 δ 的分布又受分块粒度、RoPE 时间跨度、
qk_norm 后的 logit 尺度影响。消融实验该扫的是这四个量（含"精确预算的分配方式"），而不是只扫"稀疏率"。

## 7. 从输出误差到"背景闪烁"（可证伪的因果链）

这一节是把项目从"工程移植"拉成"研究"的关键。

```text
① 硬丢弃使每行输出偏差 ≈ -ρ_i (o_i - o_i^C)，大小与方向随行变化。
② 视频相邻帧高度冗余，相邻帧同一空间位置的偏差高度相关；但 ρ_i 会随帧轻微波动，
   结果是一段"时间上低频、空间上结构化"的偏差抖动。
③ 低纹理背景区域的注意力分布更平坦（熵更高、没有强对齐的少数 key），
   因此背景 token 的 ρ_i 系统性高于前景 token -> 背景偏差更大。
④ 主观感知上这就是"背景忽明忽暗/色块脉动"；前景被强对齐 key 主导，变化不明显。
⑤ 一阶补偿把偏差乘以 ε(Δ) ≈ Δ²e^Δ/2，低频抖动被压制，残余项是高阶（更接近零均值、
   时间相关性更弱）的扰动 -> 感知上从"闪烁"变成"轻微颗粒感"。
```

由此得到四条**可证伪预测**：

```text
P1  ρ_i 在背景 token 上显著高于前景 token。                  检验: 逐层统计 ρ_i 的空间分布
P2  flicker_index 与平均 ρ 近似线性（跨稀疏率拟合直线）。      检验: 配对闪烁指标 vs ρ_mean
P3  加入一阶补偿后 flicker_index 显著下降，且降幅随 ρ 增大      检验: 三组策略配对比较 +
    （即 ρ 与"是否补偿"存在交互效应）。                              ρ×策略 交互项检验
P4  残余误差的时间频率成分发生转移：硬丢弃能量集中在低频，      检验: 背景 patch DC 序列功率谱
    补偿后向高频转移。                                        （flicker.py 已给出低频能量占比）
```

P2 是把"上界推导"与"质量指标"直接连起来的那根线：若闪烁与 ρ 呈线性，说明误差主导项确实是一阶截断项，
补偿设计就有理论依据；若明显非线性，说明主导项在别处（分母不一致、索引粒度、跨层累积误差）——
那本身也是有价值的发现。

## 8. 映射到 Wan2.1 的实现细节（踩坑清单）

```text
1) qk_norm = True
   logit 尺度被 RMSNorm 重标定，Δ 的分布与"原始 q·k"完全不同。
   => 论文给的阈值不能直接搬，必须用实测 Δ 直方图按第 6 节判据重新定阈值。
2) 3D RoPE
   旋转对 q、k 是线性的，矩的预聚合仍成立（M_C、S_C、G_C 用旋转后的 k~）。
   但 k~ 方向随时间位置发散 -> 时间跨度越长，块内 Δ 越大。
   => 分块应同时受"时间跨度"约束（视频特有结论，可写进报告）；纯按空间分块比纯按时间分块更安全。
3) 稳定化
   c_i 必须是整行真实行最大值（或至少是上界）。若只在精确集内取 max，而近似集里有更大的 logit，
   指数会溢出；工程上用逐块 max 的在线更新（FlashAttention 的 online softmax）配合。
4) 只稀疏 WanSelfAttention
   cross-attention 只有 512 个文本 token，不动；稀疏必须作用于视频 token 的 3D 全自注意力。
5) 强制精确集
   sink / 首帧 / 文本对齐最强的 token 必须进 S（对应 `sink_idx` 之类参数），否则条件被丢弃，
   画面整体崩坏。注意：这类崩溃与"背景闪烁"是完全不同的失效模式，评审很容易区分。
6) CFG 的两条分支
   每个采样步跑两遍前向，稀疏模式可共享（省掉一次选择开销），但两条分支都要替换成稀疏 kernel，
   否则端到端加速比会被腰斩。
7) 测速时关掉 --offload_model
   CPU offload 让权重每步走 PCIe，会把 kernel 层收益稀释甚至掩盖。
```

## 9. 与官方实现核对清单（动手写代码之前必须完成）

```text
[ ] 泰勒展开的变量是 logit（本文假设）还是 softmax 概率 p_ij？
    若对 p 展开，矩的结构完全不同（出现 Σ p v、Σ p² v 这类项，且 p 已被归一化），本文结论不可直接套用。
[ ] 是否同时对分子与分母做近似？有没有归一化一致性处理？
[ ] "hybrid order" 具体指什么？是否就是本文推出的"分子一阶 + 分母二阶"？
[ ] 精确集 S 的选取规则：按 logit 幅值、按块均值，还是按位置/窗口？
    （不同规则下 ρ_i 的分布差别很大，直接决定 P1 是否成立）
[ ] 是否有 per-head / per-layer 的不同稀疏率？是否有 sink_idx 之类的强制精确参数？
[ ] 原文报告的加速比是在多大的 N 上测的？
    ⚠️ 补偿开销 ∝ 1/N（结论 4），短序列上的加速比不能直接搬到 480p 设置；
    反过来，若原文在小 N 上"补偿几乎不减速"，在你的长序列上只会更快 —— 这点你可以主动讲清楚。
```

## 11. 一页速查表

```text
精确拆分:    o_i = (1-ρ_i) o_i^S + ρ_i o_i^C                       [恒等式]
一阶矩:      M_C = Σ_{j∈C} k~_j v_j^T ∈ R^{d×d},  S_C = Σ k~_j,  V_C = Σ v_j
一阶近似:    n~_i^C = M_C q~_i + (1 - c_i) V_C                    [O(d²)/query]
             z~_i^C = (1 - c_i)|C| + S_C · q~_i
二阶可行性:  分母只需 G_C = Σ k~_j k~_j^T (d×d)；分子需 T_C (d×d×d) —— 不划算
误差上界:    |e^δ - 1 - δ| ≤ δ²/2 (δ≤0)  =>  ε(Δ) ≤ (Δ²/2)e^{Δ}
输出误差:    ||ô_i - o_i|| ≲ ρ_i * ε(Δ_i)
补偿开销:    (1+ρ) d / (2N) = 0.35% (480p, ρ=0.8) / 0.15% (720p)
端到端上限:  1/(0.27 + 0.73/S) = 2.39x @ S=4.95x (480p, ρ=0.8)
分段判据:    Δ ≥ ln(|C|/(ε_tol z^S)) -> 硬丢弃
             (Δ²/2)e^Δ ≤ τ          -> 一阶补偿（τ=10% 时 Δ ≤ 0.37）
             否则                    -> 保持精确 / 缩小分块粒度
```
